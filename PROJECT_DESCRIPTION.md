# Mô tả dự án

`text_stoty_ai` là một studio AI viết bằng Next.js và TypeScript, do `tysdzai` phát triển, tập trung vào việc biến nội dung truyện dài, tiểu thuyết hoặc kịch bản thành asset sản xuất video ngắn. Dự án hỗ trợ nhập nội dung, chia tập, phân tích nhân vật, bối cảnh và đạo cụ, tạo asset hình ảnh nhất quán, dựng storyboard, sinh thoại, tạo giọng đọc, tạo video theo từng panel và quản lý thư viện asset trong giao diện web đã được bản địa hóa. Kiến trúc hiện dùng React 19, Next.js 15, Prisma, BullMQ workers, Redis, MySQL, object storage và các adapter cho LLM, image, video, audio provider. Hệ thống prompt được tách theo catalog và locale, với `vi` là ngôn ngữ chính, `en` là ngôn ngữ phụ, template tương ứng nằm ở `.vi.txt` và `.en.txt`.

Về token coding mỗi ngày, đây là codebase cỡ vừa đến lớn và khá nặng ngữ cảnh. Một bug fix nhỏ thường cần khoảng 25.000-60.000 input token/ngày vì phải đọc component, hook, route/worker liên quan và test tập trung. Một feature bình thường hoặc lượt chỉnh localization nên dự trù 80.000-180.000 input token/ngày, nhất là khi chạm UI, API, worker, prompt và test. Một ngày refactor lớn hoặc chuẩn bị release có thể cần 200.000-350.000 input token do phải kiểm tra contract, guard, integration test và runtime flow trước khi sửa. Output token thường thấp hơn nhiều, khoảng 5.000-20.000 token/ngày cho code, ghi chú và báo cáo. Mức ngân sách thực tế nên đặt khoảng 120.000-220.000 tổng token/ngày làm mặc định, và có thể vượt 300.000 token khi chỉnh hạ tầng chung hoặc workflow AI nhiều bước.
